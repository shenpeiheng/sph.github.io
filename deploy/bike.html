基于 Akile VPS + Cloudflare + CPA 的 AI 代理服务网络架构方案 ​

一个域名，一个入口，多模型统一管理

还在为各种 AI 客户端分别配置不同 API 而烦恼吗？本方案将指导你：购买海外 VPS、注册自有域名并接入 Cloudflare、搭建属于自己的 VPN 节点（配合 Karing 客户端魔法上网）、最后部署 CPA（CLI Proxy API Management Center），把 Grok / GPT / Codex / Claude / Gemini 等模型通过 OpenAI 兼容接口统一反代调用。低成本 · 高可用 · 多模型 · 统一管理。

整体架构图 ​

整体分为五层：

  • 用户访问层：开发工具 / 客户端（Cursor、VS Code、Cherry Studio、Claude Code 等），通过 OpenAI 兼容接口调用
  • 域名与 CDN 层：spaceship 注册域名 + Cloudflare DNS / CDN / SSL / 安全防护
  • 海外服务器节点：Akile 美国节点 / 日本节点，Linux 服务器 + Docker 环境
  • CPA 服务部署层：CLI Proxy API Management Center（Web 管理控制台）+ 账号池管理 + 附加服务
  • AI 模型服务层：Grok、GPT、Codex、Claude、Gemini 等（通过 CPA 反代调用）

部署操作 ​

首先你得准备：

  • 主机（海外 VPS）
    • 这里尽量购买国外的服务器，可以免备案，举例用：AkileCloud
    • 推荐选择美国节点（US）或日本节点（JP），Linux 服务器 + Docker 环境 + 公网 IP + 稳定网络
    • 也可以用我这个推荐的连接：host
    • 这里我用的是AkileCloud，价格便宜，高可用 / 负载均衡，还可以魔法上网。
  • spaceship
    • 6位数字域名 US$0.67/年 -- ( *.xyz )
    • 支持支付宝支付，预计6元一年
    • 更改一下dns，指向到 Cloudflare
  • Cloudflare（0 元使用）
    • 添加域名管理，把刚刚的域名转入到Cloudflare，选择free套餐
    • 提供：DNS 管理 / SSL 证书（HTTPS）/ CDN 加速 / 反向代理·负载均衡 / 安全防护（WAF / DDoS）
    • 添加到你的主机IP，选择 * 可以支持泛域名
    • 添加证书，自动管理，自动续约

搭建 VPN 节点（魔法上网） ​

VPS 准备好后，先在服务器上搭建代理节点，后面下载 Docker 镜像、注册账号等都需要。

  • 安装 3x-ui 面板（一键脚本）：
    bash
    bash <(curl -Ls https://raw.githubusercontent.com/mhsanaei/3x-ui/master/install.sh)
  • 登录面板（http://ip:端口/），添加入站规则，推荐协议：
    • VLESS + Reality（目前最抗封锁，推荐）
    • VMess + WS + TLS（可套 Cloudflare CDN）
  • 记录节点信息：地址（IP 或域名）、端口、UUID、公钥等，后面 Karing 要用
  • 建议在 Cloudflare 开启小云朵（CDN 代理），隐藏源站 IP

Karing 客户端配置 ​

Karing 是一款全平台（Win / Mac / iOS / Android）的代理客户端，简单好用。

  • 下载安装：Karing Releases
  • 方式一：直接添加节点链接
    • 复制 3x-ui 面板里的分享链接（vless://...），在 Karing 中「添加配置 → 从剪贴板导入」
  • 方式二：订阅链接
    • 在 3x-ui 面板开启订阅，把订阅地址填入 Karing
  • 选择节点，开启系统代理，测试延迟，能访问 Google 即成功

搭建 CPA（CLI Proxy API Management Center） ​

CPA 是核心：CLI Proxy API 服务 + Web 管理控制台，负责账号池管理、模型路由与反代、请求日志/监控。

  • 服务器上安装 Docker 环境：
    bash
    curl -fsSL https://get.docker.com | sh
systemctl enable --now docker
  • Docker 部署 CPA：
    bash
    docker run -d \
  --name cli-proxy-api \
  --restart always \
  -p 8317:8317 \
  -v /root/cli-proxy-api:/app \
  -e SECRET_KEY="你的管理密码" \
  router-for-me/cli-proxy-api:latest

    具体镜像名 / 端口 / 参数以你使用的 CPA 项目文档为准，这里以常见部署方式举例

  • 配置 Nginx 反向代理 + Cloudflare SSL，绑定域名（如 api.yourdomain.com），对外提供 HTTPS 访问：
    nginx
    server {
    listen 443 ssl;
    server_name api.yourdomain.com;

    location / {
        proxy_pass http://127.0.0.1:8317;
        proxy_set_header Host $host;
        proxy_set_header X-Real-IP $remote_addr;
    }
}
  • 访问 Web 管理控制台，确认服务健康检查正常

账号获取层（账号池管理） ​

CPA 支持「注册机 / 自动化注册」批量生成账号池：

  • 自动化注册 Grok Free、GPT Free，获取 OAuth 认证文件
  • 常见认证文件（放在 CPA 配置目录）：
    bash
    /root/cli-proxy-api/
├── grok-xxx.json     # Grok 账号池
├── gpt-xxx.json      # GPT 账号池
├── codex-xxx.json    # Codex 账号池
└── ...
  • 在 Web 管理控制台中可以查看各账号池状态：Grok 账号池 / GPT 账号池 / Codex 账号池 / 其他模型账号池
  • CPA 自动完成：账号池管理 → 模型路由与反代 → 请求日志/监控

客户端调用（OpenAI 兼容接口） ​

所有支持 OpenAI 兼容接口的客户端都能直接用：

  • 接口地址：https://api.yourdomain.com/v1
  • API Key：CPA 管理控制台里生成的密钥
  • 支持的接口：Chat Completions / Responses API / Embeddings / Tools & Function Calling
  • 客户端示例（Cherry Studio / Cursor / VS Code / Claude Code 等）：
    bash
    OPENAI_BASE_URL=https://api.yourdomain.com/v1
OPENAI_API_KEY=sk-xxx
  • 可调用的模型：Grok (xAI)、GPT (OpenAI)、Codex (OpenAI)、Claude (Anthropic)、Gemini (Google)、其他模型...

总结

一个域名 · 一个入口 · 多模型统一管理 · 安全稳定 · 低成本可扩展 —— 让 AI 更简单、更可控！
